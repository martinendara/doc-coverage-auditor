# Integraciones

## Integraciones disponibles
La plataforma se integra con Slack, Google Workspace y Microsoft Teams. La
integración con Slack permite recibir notificaciones en un canal.

## API
Ofrecemos una API REST documentada. Las credenciales se generan desde
Configuración > API. El límite es de 1000 llamadas por hora en plan Growth.

## Webhooks
Se pueden configurar webhooks para eventos de creación y modificación. La URL
debe responder con status 200 en menos de 5 segundos.
